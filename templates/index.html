Por que o Chrome mostrou "Não é possível instalar"?

O Google Chrome no Android exige conexão segura HTTPS para transformar um site em aplicativo instalado (WebAPK). No endereço HTTP local (192.168...), ele bloqueia "Instalar", mas libera "Criar atalho".
